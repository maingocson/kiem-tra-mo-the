Cách tạo mã truy cập
  1. Đăng nhập GitHub, vào Settings → Developer settings → Personal access tokens → Fine-grained tokens, bấm Generate new token.
  2. Expiration: chọn thời hạn (ví dụ 1 năm).
  3. Repository access: chọn Only select repositories → chỉ chọn kiem-tra-mo-the-dieu-kien.
  4. Permissions → Repository permissions → Contents: chọn Read and write. Không bật quyền nào khác.
  5. Bấm Generate token, chép mã rồi dán vào ô trên.
